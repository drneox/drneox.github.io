Política de privacidad de Grivo

Última actualización: 13 de septiembre de 2026

1. Responsable y alcance

Grivo es una aplicación para iOS desarrollada por Carlos Ganoza Plasencia, bajo la marca punkbot. Permite grabar, reproducir, transcribir y organizar audios, así como solicitar análisis opcionales mediante inteligencia artificial.

Responsable: Carlos Ganoza Plasencia.
Contacto de privacidad: contacto@punkbot.co.

Esta política describe el tratamiento de datos de Grivo para iOS. La navegación en el sitio web donde se publica esta política puede estar sujeta a prácticas adicionales del sitio, independientes de la aplicación.

2. Datos que utiliza Grivo

Según las funciones que utilices, Grivo puede tratar:

  • Grabaciones de audio y sus metadatos, como nombre, fecha, duración y tamaño.
  • Transcripciones, traducciones, informes de IA, categorías y nombres asignados a hablantes.
  • Perfiles de voz: nombres y representaciones numéricas de características vocales utilizados para sugerir coincidencias entre hablantes.
  • Preferencias, contadores de uso, saldos y datos de transacciones necesarios para gestionar compras y límites de funciones.
  • La clave API de OpenAI que introduzcas para utilizar servicios externos.
  • Datos técnicos de un grabador Bluetooth compatible, como identificador, nombre, señal, modelo, firmware, batería, almacenamiento y eventos de conexión.

No necesitas crear una cuenta de Grivo para utilizar la aplicación. Grivo no incorpora publicidad ni seguimiento publicitario y no vende tus datos personales.

3. Procesamiento y almacenamiento en el iPhone

Las grabaciones, transcripciones, traducciones, informes y perfiles se guardan en el dispositivo. Grivo no ofrece un servidor propio donde se cargue automáticamente tu biblioteca.

La transcripción local, la separación local de hablantes, el reconocimiento mediante perfiles de voz, la reducción de ruido y la traducción local se realizan en el dispositivo cuando estas funciones están disponibles. Algunas necesitan descargar previamente modelos o recursos de sus proveedores; esas descargas implican una conexión a internet y pueden comunicar datos técnicos de conexión.

Los archivos utilizan los mecanismos de protección de datos de iOS. La clave API y determinados registros de uso se guardan en el Llavero de iOS. Estas medidas reducen riesgos, pero no constituyen una garantía absoluta de seguridad.

Los perfiles de voz se conservan localmente y no se envían como perfiles a OpenAI. Sin embargo, el audio enviado mediante transcripción cloud contiene voces y un texto enviado para análisis puede incluir nombres de hablantes. La identificación puede ser incorrecta y no se utiliza como método de autenticación.

4. Funciones opcionales de OpenAI

Cuando solicitas un análisis con IA, Grivo envía el texto necesario de la transcripción, incluidas las etiquetas o nombres de hablantes presentes, y las instrucciones de la plantilla a la API de OpenAI.

Si eliges transcripción o separación de hablantes mediante el servicio cloud y ejecutas esa función, se envía el audio correspondiente a OpenAI. La transcripción local no requiere este envío.

Las solicitudes se realizan mediante conexión cifrada y utilizando la clave API que configures. OpenAI recibe también los datos técnicos necesarios para atender la solicitud, como la dirección IP y la información de autenticación de tu cuenta API. El consumo de ese servicio se rige por las condiciones de tu cuenta de OpenAI.

El contenido no se anonimiza automáticamente antes del envío. Evita enviar datos que no quieras compartir con ese proveedor.

Según la documentación de OpenAI, los datos de la API no se utilizan para entrenar sus modelos de forma predeterminada, salvo participación voluntaria. La retención depende del servicio y de la configuración de la cuenta; determinados registros de prevención de abuso pueden conservarse hasta 30 días o más cuando lo exija la ley. No debe entenderse que todos los servicios conservan los mismos datos o durante el mismo plazo. Consulta los detalles vigentes en https://developers.openai.com/api/docs/guides/your-data y su política en https://openai.com/policies/privacy-policy/.

Puedes dejar de utilizar las funciones externas y eliminar la clave API desde la configuración de Grivo. Esto no elimina retroactivamente datos que el proveedor ya haya recibido. Las solicitudes relativas a tu cuenta y los datos conservados por OpenAI deben gestionarse también con ese proveedor.

5. Grabadores externos y permisos

Si utilizas un grabador compatible, Grivo se comunica directamente con él por Bluetooth. La sincronización automática puede transferir archivos del grabador al iPhone cuando está habilitada. Esa transferencia no equivale a un envío a OpenAI.

Grivo solicita acceso al micrófono para grabar desde el iPhone y a Bluetooth para conectar grabadores. Si activas el bloqueo biométrico, iOS realiza la autenticación; Grivo no recibe los datos biométricos de Face ID.

Puedes revisar o retirar permisos en los ajustes de iOS. Algunas funciones dejarán de estar disponibles si retiras el permiso necesario. Asegúrate de contar con las autorizaciones necesarias para grabar y tratar las voces o datos de otras personas.

6. Compras, límites y diagnósticos

Apple gestiona los pagos y las compras dentro de la app. Grivo utiliza información de transacciones y del estado de compra para verificar funciones Pro o conceder saldo. No recibe los datos completos de tu tarjeta.

Los contadores y registros de uso necesarios para aplicar límites y evitar aplicar dos veces una misma transacción se conservan localmente. Algunos registros del Llavero pueden permanecer tras desinstalar la aplicación.

Los diagnósticos disponibles en la app pueden incluir identificadores Bluetooth, nombres de archivos, fechas, estados y errores. Si decides copiarlos o enviarlos para recibir soporte, revisa su contenido antes de compartirlos. No incluyas claves API ni grabaciones sensibles si no son necesarias.

Si nos contactas, utilizaremos la información que envíes para atender tu solicitud y la conservaremos mientras sea necesaria para gestionarla o cumplir obligaciones legales.

7. Conservación, eliminación y exportación

El contenido local permanece hasta que lo elimines o deje de estar disponible en el almacenamiento del dispositivo. Puedes borrar grabaciones desde Grivo, eligiendo el iPhone, el grabador externo o ambos, cuando corresponda. Borrar una copia no implica borrar las otras.

Puedes gestionar y eliminar perfiles desde las opciones de perfiles de voz. Eliminar un perfil no necesariamente elimina los nombres que ya aparecen en transcripciones guardadas; estos pueden revisarse por separado.

Las funciones de compartir permiten exportar contenido a los destinos que elijas. Las copias exportadas, las copias de seguridad que pudieran existir y los datos recibidos por terceros deben gestionarse también en esos destinos. No asumimos que desinstalar Grivo borre todas esas copias.

El desarrollador no puede acceder ni eliminar remotamente los archivos que solo están en tu iPhone o en tu grabador.

8. Proveedores, transferencias y tus derechos

Apple, OpenAI y los proveedores de descargas de modelos pueden tratar datos técnicos o de servicio bajo sus propias condiciones. Los servicios externos pueden procesar información en países distintos al tuyo, de acuerdo con sus condiciones y mecanismos de protección aplicables.

Dependiendo de la legislación que corresponda, puedes solicitar acceso, corrección, eliminación, oposición, limitación o portabilidad respecto de datos personales tratados por el responsable, así como retirar el consentimiento cuando corresponda y presentar una reclamación ante la autoridad competente. Para ejercer estos derechos sobre información que nos hayas enviado, utiliza el contacto indicado al inicio. Para contenido exclusivamente local, utiliza las opciones de la app y del dispositivo.

Grivo no está dirigida específicamente a niños. Las funciones externas están sujetas también a las condiciones de edad de sus proveedores.

9. Cambios en esta política

Publicaremos las modificaciones en esta página y actualizaremos la fecha. Si un cambio requiere información adicional o una nueva autorización, se solicitará conforme corresponda antes de aplicar el nuevo tratamiento.
